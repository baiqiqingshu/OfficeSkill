# 源码整理

1. inspect 默认最多 100 个文件、每文件 12 KB、总读取 160 KB。不执行代码；排除 .git、依赖、构建产物、环境变量、凭证、锁文件、数据文件、符号链接。报告仅给相对路径、技术线索和有行号的界面标记；报告也属于内网数据。
2. 选择 2–5 个相关视图/组件，读取必要源码。根据实际路由、字段、导航与 token 理解产品；没有证据的部分标为设计假设，不复制完整敏感源码到规范。
3. sources 填相对路径和简短依据；区分“源码已实现”和“原型补充”。本工具不自动理解业务，也不将 UI 框架源码自动编译为原型。
4. assets 明确声明 `[{"source":"./local/banner.png","name":"banner.png"}]`，source 相对 page.json 解析，输出 assets/banner.png。支持本地 PNG/JPEG/WebP/GIF/ICO/WOFF/WOFF2/TTF/OTF；拒绝 SVG，避免其脚本/外链能力。图片区块填 `"src":"assets/banner.png"`。自带素材须具有使用许可。
5. 保留原业务语义，使用脱敏示例。原型不连接真实 API，不读取或复制凭证。接入真实系统属于另一个明确任务。
