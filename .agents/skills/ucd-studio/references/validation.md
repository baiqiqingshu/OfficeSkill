## 复现

从技能包的上级目录运行：

```text
python -m unittest discover -s ucd-studio/tests -v
node ucd-studio/tests/browser.mjs
python ucd-studio/scripts/ucd.py check --dir ucd-studio/demo/dashboard
```

浏览器测试要求宿主环境已提供 Playwright 及其 Chromium；本技能不会自动下载或安装它们。测试创建独立临时输出，并返回截图目录、页面数及异常数。
