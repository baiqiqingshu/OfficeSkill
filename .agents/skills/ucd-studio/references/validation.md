## 渐进式披露

普通模板不再要求搜索样式/布局、读整份 page.json、再次 build/check。init --config 一次覆盖业务字段，生成同时完成结构与离线静态检查；已知字段直接 patch。summary 返回页面区块目录，--block 返回单个区块；show 默认元数据，--example 返回 JSON，--code 才展开 HTML/CSS。复杂用法在入口的条件链接中，不自动加载。

此改动减少规定步骤与上下文读取，不代表已实测任意内网模型的响应速度。浏览器交互与视觉验证仍有独立价值，不用静态检查替代。

## 复现

从技能包的上级目录运行：

```text
python -m unittest discover -s ucd-studio/tests -v
node ucd-studio/tests/browser.mjs
python ucd-studio/scripts/ucd.py check --dir ucd-studio/demo/dashboard
```

浏览器测试要求宿主环境已提供 Playwright 及其 Chromium；本技能不会自动下载或安装它们。测试创建独立临时输出，并返回截图目录、页面数及异常数。

## 实际边界

尚未在特定内网低性能模型上做端到端成功率或速度评测。降低模型负担的实现依据是按需检索、小份 page.json/补丁和本地确定性生成；不承诺任何模型都能自动理解复杂源码。可在目标环境用 USAGE.md 的三类提示词进行验收。

本次浏览器验证仅覆盖 Chromium，不代表所有浏览器版本与任意扩展环境。无外部请求是这些受测页面和操作的观察结果；静态扫描不能证明任意新 JS 安全，技能也不能控制宿主模型、插件或操作系统网络。手工扩展或接入真实业务后需重新检查。

原型交互使用本地示例数据，不包含真实审批、账号权限、文件上传、后端提交或持久化。
