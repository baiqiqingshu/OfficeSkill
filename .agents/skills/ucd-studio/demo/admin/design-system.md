## 交互与状态

本页已配置的行为：

- 页面主操作打开原生 dialog；Esc 或“取消”关闭并返回触发按钮，校验通过后显示本地草稿反馈，不写入业务记录。
- 本页导航使用区块锚点及当前项标记，不代表额外业务路由。
- 表格支持任意字段搜索、状态筛选、数字感知排序与分页；禁用不可用的翻页按钮。无匹配时可清除筛选；状态预览包含加载骨架、空与错误，就近恢复示例记录或重试，均无网络请求。
- 所有数据仅保存在当前页面内存，刷新恢复示例；没有登录、后端、上传、真实持久化或权限控制。

扩展组件时沿用同一状态语言：hover/active 给出操作反馈，focus-visible 保持可见，disabled 表明不可用；异步内容提供 loading、empty、error 与恢复路径，成功反馈沿用操作名称。这是扩展约定，不代表每个静态区块都具备异步行为。权限不足等真实业务状态需依据项目资料补充，不从原型推定。
