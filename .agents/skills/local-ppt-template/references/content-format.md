# 填充内容 Markdown 格式

推荐先用 `scaffold` 生成骨架，只替换内容。无需 YAML，也无需写 Python。

## 页面与输入映射

```markdown
# 演示主题（此行可省略）

## page: page_01 layout: cover

### title: text

Kubernetes 入门

### subtitle: text

核心概念与一次应用部署

## page: page_02 layout: title_body

### title: text

容器编排

### body: text

**容器**提供一致的应用运行环境。
Kubernetes 管理部署、扩缩容和故障恢复。
```

- 页面标题固定为 `## page: 页面ID layout: 布局ID`。
- 元素标题固定为 `### 输入ID: text`、`### 输入ID: image`、`### 输入ID: table` 或 `### 输入ID: array`。
- 页面 ID 在整篇 MD 中唯一，输入 ID 在本页唯一；ID 使用英文开头的字母、数字、`_`、`-`。
- 布局 ID 和输入 ID 来自模板说明。相同布局可重复使用，页面按 MD 顺序生成，可任意挑选/重复模板页面。
- 输入类型必须匹配。模板输入可以省略；未提供的元素按空内容处理并从输出页移除其输入形状（数组则移除全部样例）。`required` 只表示建议填写，不会阻止生成。显式提供空的 `text` 元素也表示空内容。
- 普通文字每行对应一个段落，空行对应空段落。
- 分点语法（每级缩进两个空格）：

  ```markdown
  - 普通符号分点（•）
  1. 数字分点，按书写的数字渲染
  2) 括号数字分点
  - [✓] 图标分点：方括号内为符号字符
  - [★; #E85A2E] 可给图标指定颜色
  - [➤; font:Segoe UI Symbol; #2563EB] 可同时指定符号字体和颜色
    - 缩进一级
  ```

  数字分点使用自动编号渲染书写的数字（`3.` 显示为 "3."）；图标分点的符号为 1-8 个 Unicode 字符（如 `✓ ★ ▶ ➤ ●`），字体须为目标机器本地已安装字体。
- 字数不包含段落换行、项目符号标记和样式标记。文本输入框在模板位置内使用声明的最大宽高，若约束比原框更小，则缩小输出框并按缩小后的宽高检查换行。
- 不支持额外页面属性、水平分隔线、代码块文本、链接、自动新增元素。正文包含 `##`/`###` 时请改写，不要把页面标题放入正文。

## 局部文字样式

简单强调优先使用 Markdown：

```markdown
**前两个字**使用粗体，其他内容继承模板。
这里有*斜体*，这里有***粗斜体***。
```

需要字体、颜色或字号时使用一个 span：

```html
<span style="font-family: Microsoft YaHei; font-size: 20pt; color: #2563EB; font-weight: bold">重点</span>内容保持模板样式。
```

支持的 style 项：

| 项 | 值 |
| --- | --- |
| font-family | 单个本地字体名称，如 Microsoft YaHei、Arial |
| font-size | 正数 + pt，如 20pt，不得超过该输入最大字号 |
| font-weight | bold / normal |
| font-style | italic / normal |
| color | #RRGGBB |
| text-decoration | underline / none |

也支持 `<b>`、`<strong>`、`<i>`、`<em>`、`<u>`。嵌套标签必须闭合。Markdown 的一对星号标记须在同一段且同一 HTML 文本片段内闭合；需要跨 span 加粗时用 `<b>前缀<span style="color: #2563EB">片段</span></b>`。字面星号写 `\*`。字面小于号写 `&lt;`。未指定的样式继承该输入的默认 run 样式，局部样式结束后不会影响后续文字。

模型只需使用加粗/斜体即可生成普通 PPT。不要为每个片段重复写全部样式。脚本只写字体名称，不下载/嵌入字体；目标电脑需安装相应字体。

## 图片

```markdown
### image: image

{"src":"images/architecture.png","fit":"contain","alt":"集群架构示意图"}
```

图片仅从本地读取。相对路径按填充 MD 所在目录解析，也支持本地绝对路径。拒绝 URL、UNC 网络共享、HTML 图片和 base64 图片。

`contain` 保持比例，完整显示并居中；`cover` 保持比例，居中裁剪。`fit` 省略时为 `contain`。

可指定宽高（cm）：

```json
{"src":"images/architecture.png","fit":"cover","width_cm":12,"height_cm":8}
```

指定尺寸不得超过模板说明中的最大宽高；省略尺寸时使用模板限制。像素上限是宽像素 × 高像素；不执行下载和远程图片解析。

## 表格

最简单使用 Markdown 表格：

```markdown
### data: table

| 对象 | 用途 | 示例 |
| --- | --- | --- |
| **Pod** | 容器运行单元 | API 服务 |
| Deployment | 管理副本与更新 | 三个副本 |
| Service | 提供稳定入口 | 集群内访问 |
```

每行列数相同；表头计入行数。单元格中 `\|` 表示字面竖线。单元格可用同样的局部文字样式。表格会保留可编辑的原生对象与模板风格，未用的网格行列会收起。

需要指定表格宽高或列宽时使用 JSON（可加 json 围栏）：

````markdown
### data: table

```json
{
  "rows": [["对象","作用"],["**Pod**","运行容器"],["Service","稳定入口"]],
  "width_cm": 20,
  "height_cm": 8,
  "column_widths_cm": [8,12]
}
```
````

列宽总和必须等于表格宽度。省略列宽时各列等宽，省略宽高时使用模板限制；各行等高。

## 数组元素

数组输入对应模板中的两个样例形状：它们的位置差定义条目的排列方向和间距（横向/纵向/对角）。填充时按条目个数沿该向量复制排列；条目数必须在说明的 `min_items..max_items` 范围内，且最末条目不得超出页面。

```markdown
### items: array

- 条目一
- 条目二
- 条目三
```

每个 `- ` 行是一个条目。条目包含多个文本位（如「序号 + 标题 + 说明」的组合卡片）时用 ` || ` 分隔字段，字段个数不得超过说明中的文本位数：

```markdown
### items: array

- 01 || 需求分析 || 梳理范围与验收标准
- 02 || 开发联调 || 按里程碑推进
```

也支持 JSON（可加 json 围栏）：

````markdown
### items: array

```json
{"items": [["01", "需求分析", "梳理范围"], ["02", "开发联调", "按里程碑推进"]]}
```
````

图片数组的条目为本地图片路径或图片对象：

```markdown
### items: array

- images/shot1.png
- {"src":"images/shot2.png","fit":"cover"}
```

条目字段可以使用与正文相同的 `**加粗**`、`*斜体*`、`span` 局部样式，以及分点语法（JSON 字符串中的 `\n` 可分段）。条目中的空装饰形状（如卡片底色）不属于文本位，保持模板原样。

## 超限处理

`validate` 和 `generate` 都会检查类型、字数、字号、估算换行/高度、图片像素/尺寸和表格行列/单元格容量。失败时不会生成不完整 PPT，也不会替换已有输出。修改报错元素后重试。自动换行属于保守估算，最终仍需本地视觉检查。
