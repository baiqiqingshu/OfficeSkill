# UCD Studio 模板与默认规范

## 目标与范围

依据本地 `impeccable` 的 Operate 模式及 `frontend-design`，完善既有公司内网原型模板。服务对象为每天办理审批、查询和协作任务的内部业务人员；成功标准是快速找到主任务、辨认状态、完成本地演示操作。

本次继承既有浅色企业蓝、系统中文字体、紧凑表格的视觉方向，属于现有模板的规范化完善。覆盖 admin、dashboard、workbench、form、detail、kanban，及组件示例、模板导航、三种输出模式。保持 Python 标准库生成、离线 HTML 和现有配置兼容，不引入构建依赖。

生成器与运行时升级为 1.1.0，page.json 协议仍为 version=1。固定运行库的旧交付物继续受版本与摘要保护；升级时在新目录生成并迁移，不重算旧清单以跳过保护。仓库内示例通过新目录完整生成后更新，保留手工扩展的处理规则。

## 设计决策

- 色彩：默认主色 `#1d4ed8`、背景 `#f5f6f8`、内容面 `#ffffff`、正文 `#202938`、辅助文字 `#596579`。主色仅承担操作、焦点与当前选择；状态颜色配合明确文字。
- 字体：Segoe UI / Microsoft YaHei / PingFang SC / system-ui。固定字号层级，正文 14px、数据与控件 13px、辅助文字至少 12px、页面标题 24px（窄屏 22px）。数字对齐，不使用装饰性展示字体。
- 结构：稳定侧栏与顶栏，标题直接说明任务；不增加装饰眉题、营销首屏、无依据的指标或重复卡片。通过网格、留白、分隔线体现信息层级。
- 控件：共用语义 token、可见键盘焦点、明确 hover/active/disabled；加载、空、错误及恢复路径可演示。表单保留原生语义及校验。
- 响应式：桌面保持任务密度，窄屏结构重排；表格只在自身容器滚动，不缩小为不可读文字。支持减少动态效果偏好。
- 规范：默认规范随实际主题 token、密度、输出模式和存在的区块生成，区分已实现行为、设计要求及人工验证边界。不得承诺不存在的交互。

## 布局职责

| 模板 | 主任务 | 结构重点 |
|---|---|---|
| admin | 查询和筛选记录 | 筛选与表格优先，状态反馈就近显示 |
| dashboard | 了解待办与趋势 | 汇总服务于待办，趋势使用已有示例数据 |
| workbench | 在工具、队列和动态间协作 | 主队列比辅助入口有更高权重 |
| form | 准确填写申请 | 主表单与说明分栏，必填和校验可理解 |
| detail | 核对上下文与处理记录 | 属性、页签与时间线职责明确 |
| kanban | 推进任务阶段 | 阶段、数量和移动反馈一致 |

## 实施分工与顺序

1. 模板子代理：完善 CSS、页面骨架、渲染器、运行时、主题及导航页，维护既有接口。
2. 规范子代理：同步规范生成逻辑、技能入口与条件参考，确保规范描述与实际实现一致。
3. 独立验证子代理：执行现有校验及浏览器检查，查看桌面、窄屏和状态截图，不新增测试代码。
4. 主代理：管理决策、审阅结果、协调修复、同步 docs 验证记录并提交本次改动。

## 验收

六种布局可生成并离线浏览；三种输出模式仍工作；生成规范反映实际配置；主任务与关键状态可操作；桌面、中屏和窄屏无页面整体横向溢出；交付示例重新生成。验证只使用已有工具和临时检查，不安装依赖，不新增测试代码。
