# UML Studio 工作台设计

## 目标与范围

模式为 Operate：帮助用户查看图、修改内容、调整样式和导出。保留已有海蓝图形主题、表单语义与离线行为，精简工作台 chrome 的视觉层级。画布是核心内容，不增加营销首屏、装饰标语、无意义序号或重复捷径。

现状中的暖纸工具栏、蓝色表单和海蓝图形各自成体系；本轮统一工具层为海蓝中性色。把“修改图表内容”与“调整图形样式”分成两个明确入口，避免让全部设置同时争夺空间。

## 布局

```text
UML Studio       本地离线工作台          导入    保存 HTML
────────────────────────────────────────────────────────
文档名称       图表标题                    编辑图表  调整样式
图表列表       图型 / 元素数量 / 待保存状态
               格式  倍率  导出图片  复制PNG  更多导出
               ┌──────────────────────┬───────────────┐
新增图表       │                      │ 内容编辑      │
复制 / 移除    │       图表画布       │ 按需打开      │
               │                      │ 表单 / JSON   │
               └──────────────────────┴───────────────┘
               样式与布局（默认收起；进阶参数分组展开）
```

左对齐文字与表单标签。桌面列表宽 256px，内容编辑器 360–400px；不足以容纳画布和编辑器时改为上下排列。手机使用列表抽屉，主操作自动换行，不通过缩小字体解决拥挤。

## Token

| 用途 | 值 |
|---|---|
| 工作区底色 | `#f3f6f9` |
| 内容表面 | `#ffffff` |
| 正文 | `#203c52` |
| 次要说明 | `#526b7d` |
| 操作蓝 | `#2167a8` |
| 分隔线 | `#cfdae4` |

中文字体优先 `Microsoft YaHei`、`PingFang SC`，英文回退 `Segoe UI`；全部使用本机字体。常用正文 13–14px，标题 24px，次要说明不低于 12px。JSON 使用本机等宽字体。间距使用 4/8/12/16/24px；面板只用边框区分，不叠加装饰阴影。

### 图表纯白主题

增加可直接发现的“纯白”预设 `white`，用于全部 18 种图型的预览和图片导出。背景与节点表面为 `#ffffff`，正文 `#193b56`，说明 `#526b7d`，主线 `#2167a8`，边框 `#9bb7cc`。保留原有 `ocean` 默认值及其他主题；主题选项与主题数量从 `themes` 动态读取。此预设只改变图表配色，不改变工作台 chrome。已有显式样式仍按原有优先级覆盖主题。

## 交互与状态

- 编辑与样式按需展开；打开后可立即使用键盘操作。高级字体、尺寸与配色采用渐进披露，主题预设仍可直接发现。
- “已应用”指数据已显示到画布；“待保存 HTML”指文件尚未重新下载，二者不可混淆。
- 表单草稿与 JSON 草稿在未应用时明确提示；保存/导出继续遵循原有草稿确认流程。
- 加载和导出中的按钮显示动作状态，错误保留具体原因与恢复入口。
- 所有交互保留可见焦点，列表当前项有明确选中背景；尊重减少动态效果设置。

## 验证约定

独立验证 agent 负责桌面与窄屏实际渲染、主操作和离线再打开检查，不新增测试代码。检查编辑器与样式展开、表单应用、JSON 无效输入、图表切换、鱼头样式、图片导出以及 HTML 再导入；主 agent 最后运行 impeccable 机械检测并记录结果。
