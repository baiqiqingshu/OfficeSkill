# UML Studio 模板工作台

本轮以现有离线绘图组件为基础，依据 impeccable 的 Operate 原则和 frontend-design 规范精简操作界面。图表数据、自动布局、18 种图型、多图文档、主题、编辑器与导出能力继续保留。

## 常用流程

1. 在左侧选择图表，或使用“新增图表”创建示例。
2. 点击“编辑图表”，修改表单后点击“应用表单”；也可切换 JSON 源码后应用。
3. 点击“调整样式”，展开画布下方的主题、配色及进阶参数。需要白色图片背景时选择“纯白”；默认仍为“海洋蓝”。
4. 使用画布上方的“导出图片”或“复制图片（PNG）”。格式与倍率直接可选；文档 JSON 位于“更多导出”。
5. 使用顶部“保存 HTML”下载包含全部已应用图表的离线文件。修改不会自动覆盖原磁盘文件；未应用草稿有独立提示。

桌面默认优先显示画布，编辑器按需打开；窄屏图表列表使用可关闭的抽屉，编辑区转为整行，正文与控件保持可读字号。

## 纯白图表主题

全部 18 种图型均可选择“纯白”主题。它将导出图表背景设为 `#ffffff`，保留深色文字和海蓝线条；主题保存在 JSON 与离线 HTML 中。CLI 使用 `--theme white`，或在图表 JSON 中设置 `"theme":"white"`。显式 `style.background` 仍优先于主题预设；需要完全采用预设时移除该覆盖或在网页重新选择主题。
