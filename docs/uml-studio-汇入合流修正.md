# UML Studio 汇入合流连线修正

## 1. 现象

登录示例（`tests/fixtures/login.json` 的 `activity`）中，“提示账号已锁定 → 输入账号和密码”的连线没有回到输入框，而是在“提示参数格式错误”右侧的转角处带着箭头停下，看上去像是连到了“提示参数格式错误”。其余汇入同一目标的连线也有类似的不确定性。

## 2. 根因

问题来自最近一次提交 `72929bf`（fan-in 合流）。`7534f0b` 及之前，汇入同一端口的连线各自走到目标端口，共用最后一段主干，每条线都正确到达目标。合流把后到的分支在“靠近主干的位置”截断并让其汇入主干，但实现存在四个缺陷：

1. **分支末端仍绘制箭头**。截断点位于主干中途，箭头指向主干上的某一点，读图时会被当成指向附近节点。
2. **截断点贴在主干拐角上**。平行通道的跳接固定取重叠区间的极端位置（`lo+1` / `hi-1`），正好落在主干从源节点出来后的第一个拐角，形成“左通源节点、上通目标、右通分支”的三向接口，方向无法判断。
3. **目标端裁剪误用于合流端**。`routeResult` 对每条路线的末点执行 `clipEndpoint(..., target)`，合流后末点是主干上的汇合点，却仍按目标节点（菱形、起止圆等）裁剪，汇合点会被拉到目标轮廓上，与主干脱开。
4. **不检查样式与其它路线**。不同 `kind`、虚实线、无箭头的关联线也会合并；汇合点或跳接线段还可能压在无关连线上（登录示例 LR 紧凑布局中，合流末端落在另一条连线的竖线上，看起来像连到了“生成访问令牌”）。

## 3. 修正

修改集中在 `src/graph.ts`：

- **只合并同类连线**：同一入口端口、同 `kind`、同虚实线 / `arrow` / `thick`，且末端有箭头的连线才参与合流；无箭头的关联线、带目标端标注（`toLabel`）的连线、带人工途经点的连线保持独立到达目标。
- **合流分支不画箭头**：渲染时 `route.merged` 的连线省略 `marker-end`，主干独占箭头。末端判定抽成 `edgeEndMarker`，渲染与合流共用。
- **合流分支不再裁剪目标端**：`routeResult` 对 `merged` 路线跳过目标端 `clipEndpoint`。
- **汇合点远离拐角与源端口**：
  - 汇合点与主干各顶点至少相距 `mergeClear = max(16, baseClearance)`；位于主干首段时，与源端口至少 `max(mergeClear, 32)`，避免看上去连在源节点上。
  - 平行通道跳接再额外留 8px，并沿分支自身方向取最早的可用位置（步长 8px）。
  - 仅两种情况允许落在主干顶点上：① 主干进入共用目标短柱的拐角（经典的 T 形汇合）；② 分支沿主干相同方向从拐角“身后”接入（Y 形汇合）。
- **不触碰无关连线**：汇合点和跳接线段不得与目标不同的其它路线相交、共线或接触（`touchesOtherRoute`），同目标路线之间的汇合不受限。
- **按分支段内最早候选合流**：同一分支段上有多个候选时取沿流向最近的一个，而不是第一个遍历到的主干段。

## 4. 验证

- 登录示例 TB：块 → 输入的连线沿自己的通道上行，在主干竖线中段（距拐角约 24px）并入，无箭头，输入框只有一个箭头。
- 登录示例 LR 紧凑：合流点落在共用短柱的拐角，不再压在“生成访问令牌”的连线上。
- 回归测试 `tests/edge-routing.test.mjs` 新增“merged fan-in branches show no arrowhead and join their trunk clear of its corners and source stem”，覆盖登录 TB、登录 LR 紧凑和汇入决策节点三种输入；该测试在 `72929bf` 的构建上失败，修正后通过。同文件中“菱形端点位于顶点”的检查对合流分支只检查源端。
- 对 `scenarios.json`、`gallery.json`、`templates.json`、`quickstart.json` 与登录示例各取 4 种布局（默认、紧凑 LR、宽松 TB、均衡 LR）共 216 次渲染做审计，229 条合流分支全部满足：无箭头、末端落在同目标主干上、汇合点符合上述间距规则。审计脚本唯一的告警（`支付域 · 模块划分`）来自同一端口上 `dependency` 与 `realization` 两种 `kind` 的虚线，二者按设计不合并，属于审计比较范围过宽，不是合流缺陷。
- `npm test`：126 项通过。

## 5. 后续

- 合流目前只处理末端（汇入）；同源的分叉仍沿用共享源端短柱，不做截断。
- 汇合点不画实心圆点；若后续需要强化“相连”的视觉暗示，可只在 `merged` 路线的末端增加圆点，不影响几何。
