# UML Studio 编辑保存与手动布局

## 实施方案（2026-11-05）

以 `.agents/skills/uml-studio/src` 为事实来源，不依赖既有 docs 设计说明。保留现有离线单文件 HTML、Vue 工作台与 Node 原生图片导出架构。

### 保存完整编辑结果

- 修复 HTML 下载链路，确保当前图表的文字、主题、样式和布局参数进入 `diagram-data`，重新打开后恢复。
- 保存前应用当前编辑器中有效的待应用草稿；无效草稿报错并保留，不悄悄下载旧内容。
- 提供用户点击授权的本地文件或目录保存；保存目标句柄只在本次页面会话保留。浏览器不支持时仍可下载 HTML，取消授权不计为保存成功。
- 仅在成功下载或写入后更新保存状态；下载无法确认用户最终落盘，界面如实表述。

### 自动布局配置

新增 `layout.horizontalStagger: boolean`，默认 `false` 保持当前跨列 / 跨区域连接优先水平对齐；`true` 允许 TB 流程图、活动图、泳道图中横向相连节点沿流程方向上下错开。LR 对应沿横轴错开。保留列内顺序及路由避让。

### 手动调整数据契约

```json
{
  "layout": {
    "horizontalStagger": false,
    "adjustments": {
      "elements": {
        "nodes/review": { "dx": 20, "dy": 40 },
        "nodes/approve": { "x": 320, "y": 180 }
      },
      "edges": {
        "review-approve": { "waypoints": [{ "x": 300, "y": 140 }] }
      }
    }
  }
}
```

- 元素默认保存相对自动布局的 `dx/dy`，固定 `x/y` 是显式选项，二者互斥。单位为布局内部的 SVG 逻辑坐标，不是屏幕像素。
- 元素键使用 `nodes/<id>`、`groups/<id>`、`lanes/<id>` 等语义路径；时序、鱼骨元素采用渲染器提供的可定位路径。连线使用显式 edge id；未提供时使用 `edge-<从0开始的序号>`，建议需要长期保留途经点的边显式指定 id。
- 自动布局后应用位置调整，再计算连线、标签与画布边界。折线按顺序经过所存点位；浏览器和原生导出共用同一实现。
- 画布提供位置调整模式，元素拖动与原有空白平移区分；途经点可新增、拖动和删除。可查看参数、恢复自动布局，保存 HTML / JSON 保留全部参数。
- 参数在普通编辑时不要求用户理解数据结构；高级用户与 agent 可在 JSON 中直接编辑。清空仅删除调整参数，保留文字、样式和业务关系。

## 实施结果

### 保存与恢复

- “保存 HTML”先验证并应用有效的表单草稿、各图 JSON 草稿，然后下载包含完整文档的离线 HTML。多个图表的源码草稿可一次保存。
- 整个文档 JSON 与单图草稿、当前表单与该图 JSON 同时修改时，提示先应用所需版本，不自行选择覆盖。无效草稿停止保存并保留。
- 顶部“授权本地保存”优先调用 `showSaveFilePicker`；仅支持目录选择的浏览器使用 `showDirectoryPicker` 后创建 HTML。完成授权后按钮变为“同步到本地”，可通过“更多导出”另选文件。目录模式以文档标题生成文件名。
- 文件句柄只在当前页面会话有效，不写进 HTML，不记录目录权限。重新打开 HTML 后需要重新授权。取消选择或写入失败不更新保存成功状态。
- 下载提示为“已下载 HTML”，不声称浏览器已确认磁盘落盘。本地写入在流成功关闭后才更新保存快照；保存过程中产生的新修改仍提示待保存。
- 本地授权能力取决于浏览器与页面环境；不支持时按钮禁用并提示使用 HTML 下载。

### 操作入口

1. 点击“调整位置”，拖动节点、分组、泳道或标签；空白区域拖动仍为平移。释放鼠标后记录参数并重新计算连接线。
2. 双击节点图的连线增加途经点；点击连线可显示其途经点，选中点后拖动调整。Delete / Backspace 或“删除选中点”删除，“清空此连线途经点”恢复该边自动路由，Esc 取消当前拖动。
3. 图下方“查看参数”默认收起，展开可查看实际 JSON；“清空调整，恢复自动布局”只删除当前图的调整参数。
4. “调整样式”→“布局与尺寸”可切换横向连接错开；表单编辑器中的位置调整与 JSON 草稿不混合提交，未应用草稿需先应用再拖动。
5. 点击“保存 HTML”或“同步到本地”持久保存；重新打开后恢复模型、文字、样式、布局和途经点。

### 实际元素键与坐标

| 元素 | 参数键 | 移动行为 |
|---|---|---|
| 节点 | `nodes/<node-id>` | 元素移动，连接线重新路由 |
| 分组 / 泳道 | `groups/<group-id>` / `lanes/<lane-id>` | 容器带动内部成员；必要时扩展边界 |
| 连线标签 | `edge-labels/<edge-key>/main`、`from`、`to` | 标签移动并保留指向连线的引线 |
| 时序参与者 | `participants/<participant-id>` | 横移带动生命线及消息端点；纵移头部和生命线起点 |
| 时序消息 | `messages/<从0开始的序号>` | 横移标签、保留端点连接；纵移调整消息行 |
| 时序片段 | `fragments/<从0开始的序号>` | 独立调整片段框 |
| 鱼骨结果 | `fishbone/effect` | 移动鱼头与结果文字 |
| 鱼骨分类 | `fishbone/categories/<category-id>` | 分类带动所有原因；主骨连接主轴 |
| 鱼骨原因 | `fishbone/categories/<category-id>/causes/<序号>/children/<序号>/...` | 独立调整原因，支线跟随 |

`dx/dy` 是相对当前自动布局的增量，不依赖屏幕缩放；修改文字、主题、间距时会随自动布局更新。`x/y` 是元素锚点的固定逻辑坐标：节点通常为左上角，参与者使用中心横坐标等该图类型的语义锚点，以 SVG 的 `data-layout-x/y` 为准。节点图使用 `data-layout-root` 内部坐标，时序、鱼骨使用其渲染器原 SVG 坐标；画布统一通过变换矩阵换算。固定坐标元素继续拖动时更新 `x/y`，保持其定位模式。

无 id 的连线与时序消息、片段、原因使用数组索引；重新排序后应检查参数，长期维护的节点图连线建议显式提供 id。调整不会改变业务关系，也不会把移动节点自动划入另一个泳道 / 分组。手动位置可能造成重叠；清空调整可恢复自动布局。

删除元素、修改 ID 后，旧参数键惰性保留但不生效，避免阻止日常编辑；查看参数可定位旧键并清空。显式连线 ID 与另一条边的默认 `edge-N` 键发生碰撞时会明确拒绝，防止一份参数误作用于两条边。数值必须有限，成对坐标范围为 ±1,000,000。首次拖动前会先确定与原自动布局一致的标签避让间距，再应用调整，避免其它元素突然跳动。

途经点按数组顺序固定经过，适用于节点图折线路由；时序消息与鱼骨支线使用专用语义连线。点位落在节点、标题或无法通行的间隙内时，渲染拒绝该次调整并提示，保留上次成功结果。画布选择状态、命中区域和途经点控制柄不进入 SVG / 图片导出。

### API 与实现路径

- `window.UmlStudio.saveHtml()` 保持同步字符串返回接口，有未应用草稿时抛错。
- `await window.UmlStudio.saveHtmlAsync()` 应用有效草稿，返回完整 HTML 字符串。
- `await window.UmlStudio.saveToLocal(selectNew = false)` 从用户点击手势调用，可复用会话目标或另选文件。
- 数据契约：`src/types.ts`、`src/schema.ts`；核心布局与重路由：`src/graph.ts`；特殊图定位：`src/special.ts`；交互：`src/DiagramCanvas.vue`；保存与草稿：`src/Studio.vue`、`src/filesystem-save.ts`、`src/viewer.ts`、`src/FormEditor.vue`。
- 构建同步发布 JSON Schema、Node/Vue 模块、内嵌运行时和离线 Demo。旧 HTML 不会自动获得新运行时，需将旧文档导入新工作台后重新保存。
